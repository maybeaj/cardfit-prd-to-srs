# AI 통합 규칙

## 경계 — ADR-02

**AI는 두 가지만 한다.**

| 한다 | 하지 않는다 |
| --- | --- |
| ⓐ 약관 요약 (`rule_version`당 1회 캐시) | **혜택금액 계산** |
| ⓑ 추천 근거의 자연어 설명 | 조합 추천 · 게이팅 판정 |

`ExplanationModule` 은 **계산 결과를 인자로만** 받는다. 계산 클래스를 import 하면 의존성 경계 린트(`IN-04`)가 막는다.

**설명 문장의 금액은 전부 계산 산출값이어야 한다.** 새로 만든 숫자가 하나라도 있으면 위반이다(SRS §6.3 규칙4).

## 게이트 순서 — AI는 뒤에 있다

```
근거 조립 → 6항목 게이트 → (통과 시에만) AI 설명 생성
```

**미달 상태에서 AI 호출이 0건이어야 한다.** 게이트 앞에서 부르면 부족한 근거에 그럴듯한 설명이 붙어 결함이 가려진다(GR3 · STD TC-EXC-002 ③).

## 실패는 `null` 이다

AI 실패가 응답을 막지 않는다. `termsSummary`·`rationale` 이 `null` 이어도 **근거 6항목은 그대로 나가고 응답은 성공**이다(SRS §6.1.3).

## 모델 교체

- 모델 식별자는 **환경변수**다. 코드에 하드코딩하지 않는다(C-TEC-006)
- SDK 표준 인터페이스를 지켜 호출부가 특정 사업자에 묶이지 않게 한다
- **모델을 바꾸면 같은 근거에 다른 문장이 나온다.** 금지어 스캔 결과도 달라질 수 있다
- **모델 식별자 변경은 배포 게이트 ②의 재실행 트리거다**(SRS 1.5.1 신규제약 ④). 코드 변경이 없다고 통과시키면 스캔 없이 배포되는 경로가 남는다

## 비용

- **근거 설명 1건당 AI 호출 ≤ 1회** (SRS 1.5.1 신규제약 ③)
- 약관 요약은 **`rule_version` 당 1회**. 사용자 수와 무관하게 호출이 고정된다
- 호출 수·토큰·과금액을 계측한다 — REQ-NF-005는 마이데이터 과금만 다루므로 AI 비용은 별도로 본다

## 규제 — DEC-3

| 대상 | 상태 |
| --- | --- |
| **DEC-3a** 약관 요약 | ✅ 확정 — 공개 문서라 개인정보가 없다 |
| **DEC-3b** 근거 설명 | 🟡 **픽스처 모드에서만 해소.** 픽스처 페르소나는 실존 인물이 아니라 전송할 개인정보가 없다 |

**`CARDFIT_DATA_MODE=live` 로 전환하려면 D13(국외 이전 검토)이 선행된다.** 전환 체크리스트는 `BE-20` 태스크에 있다.

## 생성 문구는 스캔을 거친다

AI가 만든 문장은 사용자에게 가기 전 **금지어 런타임 스캔**을 통과해야 한다(`BE-16` · GR4). `block` 적발 시 노출하지 않고 `null` 로 대체한다 — AI는 보조 기능이므로 없어도 응답이 성립한다.
