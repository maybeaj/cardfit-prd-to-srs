# 주석 규칙

## 원칙

**주석은 왜(WHY)를 적는다.** 무엇(WHAT)은 코드가 말한다.

```ts
// ❌ 카테고리별 혜택을 계산한다
// ✅ floor 를 쓴다 — 카드사가 소수점 이하를 주지 않는다 (CALC 2.6)
```

## 반드시 주석을 남길 곳

| 상황 | 무엇을 적나 |
| --- | --- |
| 명세의 판단값을 코드에 옮길 때 | **출처 절 번호** — `// CALC 3.1 전환비용 ⓑ` |
| 직관에 반하는 순서·조건 | 왜 그 순서여야 하는가 |
| 불변식과 관련된 코드 | 어느 불변식인가 (`// I3 결정론 — 기준 시각 주입`) |
| 픽스처 전제 코드 | **실서비스 전환 시 무엇이 다시 열리는가** (D1·D4·D9·D11·D13) |
| 우회·임시 처리 | 왜 지금 이렇게 두는가, 무엇이 풀리면 고치는가 |

## 지울 주석

- 코드를 그대로 옮겨 적은 주석
- 더 이상 사실이 아닌 주석 — **틀린 주석은 없는 주석보다 나쁘다**
- 커밋 이력으로 대체되는 주석 (`// 2026-08-26 수정`)
- 주석 처리된 죽은 코드

## 문서와의 관계

**주석에 명세를 복사하지 않는다.** 값이 두 곳에 있으면 갈라진다. 절 번호로 가리키고, 값은 명세에서 읽는다.

```ts
// ❌ 임계값은 월 3,000원이고 상대 10%다
// ✅ 게이팅 두 조건 — CALC 3.3
```

예외는 **계산 상수** 다. 코드에 값이 있어야 하므로 값과 출처를 함께 적는다.
