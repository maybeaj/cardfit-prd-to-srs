# 불변식 (Invariants)

**Guardrail 5건과 직결된다.** 각 불변식은 위반 1건이 어떤 결과를 낳는지까지 함께 적는다.

## I1. AI는 계산 영역을 호출하지 않는다 (ADR-02)

- `src/domain/ai/**` 는 `src/domain/calc/**` 를 import 할 수 없다
- `ExplanationModule` 은 **계산 결과를 인자로만** 받는다
- 강제 수단은 **의존성 경계 린트**(`IN-04`)다. 단일 Next.js 앱이라 배포 경계로 막을 수 없다
- **경계 규칙에 인라인 예외(`eslint-disable`)를 두지 않는다**

> 재계산 불일치가 나오면 **이것부터 확인한다.** AI가 계산에 개입했는지가 첫 번째 용의자다(STD TC-NF-002).

## I2. 금액은 원 단위 정수다

- DB 컬럼은 `BigInt`, JSON 직렬화도 정수
- 계산 경로에 부동소수를 두지 않는다
- 반올림 규칙은 계산 명세 2.6절이 정본 — 카테고리 혜택은 내림, 월 환산은 반올림
- 배분 잔여 오차는 **배분 금액 최대 카테고리**에 흡수 (합계 오차 ≤ 1원)

> 위반 시 **GR1**(계산 오류율 ≤ 0.1%)과 REQ-FUNC-005가 동시에 깨진다.

## I3. 계산 경로에 비결정론을 두지 않는다

금지 목록 — 계산·조합·배분·근거 조립 경로에서:
- `Math.random()`
- `new Date()` / `Date.now()` — **기준 시각은 주입받는다**
- `Set`/`Map` 순회 순서, 객체 키 순서에 의존하는 정렬
- 부동소수 비교 (비율 판정은 정수 교차곱으로)

정렬은 **전순서**여야 한다. 조합 후보 정렬 5키는 계산 명세 4.3절에 있다.

> 동일 입력 10회 반복의 응답 해시가 모두 같아야 한다(REQ-NF-002 · 배포 게이트 ①).

## I4. 임계 미달이면 변경을 제안하지 않는다

```
NetBenefit(C) = Gross(C) − 전환비용(C)
ΔNet(C)       = NetBenefit(C) − Gross(현재 조합)

RECOMMEND_CHANGE ⟺ ΔNet ≥ 3,000원/월  그리고  ΔNet ÷ Gross(현재) ≥ 0.10
```

- **두 조건을 모두** 만족해야 한다. 하나만 통과한 후보를 제안하면 위반이다
- 경계는 **이상(≥)** 기준. 정확히 3,000원이면 통과
- `Gross(현재) = 0` 이면 상대 판정 **면제**
- `KEEP_CURRENT` 는 `200` 정상 응답이며 `error` 키를 두지 않는다

> **GR2 위반 = 즉시 서비스 중단.** 픽스처 P2(+4,666원 · 6.5%)가 이 경계의 시험대다.

## I5. 근거 6항목 미달이면 응답을 거부한다

- 공개 항목 6종 — 실적구간 · 통합할인한도 · 연회비 · 제외조건 · 기준일 · 미반영 항목
- 미달 시 `CF-4221` 반환. **부분 근거를 응답에 싣지 않는다**
- **AI 설명은 게이트 뒤에 있다** — 미달 상태에서 AI 호출이 0건이어야 한다
- `unreflectedItems` 는 비어도 **키를 생략하지 않는다**

> **GR3 위반.** 게이트 앞에서 AI를 부르면 부족한 근거에 그럴듯한 설명이 붙어 결함이 가려진다.

## I6. 응답 주체 ≠ 로그인 사용자면 즉시 차단한다

- **1차 방어선** Supabase RLS — DB가 행 단위 소유권을 강제한다
- **2차 방어선** `AccessOwnershipVerifier` 전건 대조 — RLS가 막아주더라도 건너뛰지 않는다
- 차단 시 `CF-4030` 반환. 응답에 **타인의 어떤 정보도 담기지 않는다** (코드·메시지만)
- 컴플라이언스 즉시 통보

> **GR5 위반 = 컴플라이언스가 PM을 우회해 단독 중단하고 규제기관에 신고한다.** 이 서비스에서 가장 무거운 실패다.

## 부수 규칙

| 규칙 | 근거 |
| --- | :---: |
| 마이데이터 호출은 **결론 1건당 ≤ 1회**. `collectOnce` 는 시나리오 반복문 **밖** | REQ-NF-005 |
| 감사 로그는 **append-only**. UPDATE·DELETE 경로를 만들지 않는다 | REQ-NF-006 |
| 완주 계측은 **측정 전용**. `resend()`·`remind()` 를 만들지 않는다 | ADR-04 · GR4 |
| "해지" 포함 결론에는 **경계 안내가 반드시** 붙는다 | REQ-FUNC-009 · GR4 |
| 30일 초과 미갱신 카드는 **계산에서 제외**한다 | REQ-NF-007 |
| 시나리오 1건이라도 실패하면 **전체를 `PARTIAL`** 로 처리하고 성공분도 노출하지 않는다 | REQ-EXC-005 |
