## 🧪 Acceptance Criteria (BDD/GWT)

**Scenario 1: 픽스처 모드에서 외부 호출이 0건이다**
- Given: `CARDFIT_DATA_MODE=fixture` 로 기동한 상태에서
- When: 페르소나 5인의 수집을 모두 수행하면
- Then: 외부 네트워크 호출이 0건이고 스냅샷이 정상 반환된다(FXT §1장).

**Scenario 2: 모드 전환이 호출부를 바꾸지 않는다**
- Given: `MyDataConnector` 가 인터페이스에만 의존하는 상태에서
- When: `CARDFIT_DATA_MODE` 를 `live` 로 바꾸면
- Then: `ApiMyDataProvider` 가 선택되고 호출부 코드는 변경되지 않는다.

**Scenario 3 (실패 흐름): 우회 호출이 린트에 막힌다**
- Given: `MyDataConnector` 외의 모듈이 주어지고
- When: 프로바이더를 직접 import 하면
- Then: 의존성 경계 린트가 실패한다. 호출을 한 곳에서 세지 못하면 결론 1건당 ≤ 1회를 보증할 수 없다(REQ-NF-005 · IN-04).

**Scenario 4 (실패 흐름): 장애와 데이터 부재가 다르게 처리된다**
- Given: 장애 주입 스위치를 켠 상태에서
- When: 스냅샷이 있는 사용자와 없는 신규 사용자로 각각 수집하면
- Then: 전자는 `CF-2001` 경고와 함께 계산이 계속되고, 후자는 필수 데이터 누락으로 처리된다(TC-EXC-003).

## ⚙️ Technical & Non-Functional Constraints
- 비용: **REQ-NF-005** 결론 1건당 마이데이터 호출 ≤ 1회. `collectOnce` 는 시나리오 반복문 **밖**에서 호출된다(SDD §5.1)
- 기술 제약: **C-TEC-001·007** 픽스처 모드에서는 Vercel 위에서 그대로 동작한다. 실연동 시 고정 IP·인증서 요건 때문에 별도 서버 분리가 필요할 수 있다(§1.5.2 갈래①)
- 아키텍처: **SDD §2.4 규칙 3** — `MyDataConnector` 만 외부 API를 호출한다
- 감사: 마이데이터 응답 코드를 전건 보존한다(REQ-NF-006)
