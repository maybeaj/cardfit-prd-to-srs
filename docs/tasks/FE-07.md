## 🧪 Acceptance Criteria (BDD/GWT)

**Scenario 1: 변경 결론에서 조합안을 저장한다**
- Given: `RECOMMEND_CHANGE` 결론이 표시된 상태에서
- When: 사용자가 조합안을 선택·저장하면
- Then: `outcome_logs` 가 생성되고 `plan_selected` 이벤트가 적재된다(북극성 분자).

**Scenario 2 (실패 흐름): 유지 결론에는 선택 버튼이 없다**
- Given: `KEEP_CURRENT` 결론 화면이 주어지고
- When: 선택·저장 버튼을 찾으면
- Then: 존재하지 않는다. 이 사용자는 분모에서 제외되므로 선택할 대상 자체가 없다(ADR-05).

**Scenario 3 (실패 흐름): 완주 화면에 독려가 없다**
- Given: 완주 확인 화면이 주어지고
- When: 재시도·리마인드·독려 문구와 버튼을 세면
- Then: 0건이다. 하나라도 있으면 GR4 위반이다(TC-FUNC-010).

**Scenario 4: 응답이 후속 액션을 부르지 않는다**
- Given: 미완주 사유를 입력해 응답한 뒤
- When: 후속 동작을 관찰하면
- Then: 자동 후속 액션 트리거가 0건이고 감사 인사로 종료된다.
