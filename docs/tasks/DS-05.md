## ✅ Task Breakdown (실행 계획)
- [ ] **완주 확인 화면 설계** — 선택 +30일 1회 발송에서 이어지는 응답 화면. 완주/미완주와 사유 입력
- [ ] **독려 표현 배제 검증표** — 재발송·리마인드·"아직 안 하셨나요" 류 표현이 0건임을 명시(ADR-04 · GR4)
- [ ] 응답 후 화면 — 감사 인사로 끝난다. **다음 행동을 권하지 않는다**
- [ ] **운영 대시보드 — 지표 4층 배치** ① 북극성(조합안 선택률 ≥ 40%) ② 보조 지표 ③ **Blind-spot 층(실행 완주율)** ④ REQ-NF-001~009 모니터링 항목
- [ ] **북극성 분모 제외 표시** — "예상대로" 결론이 "유지"인 사용자가 분모에서 빠진 비율을 함께 노출(ADR-05). 이 수치가 안 보이면 게이팅을 정직하게 지킬수록 지표가 떨어지는 것처럼 읽힌다
- [ ] **Guardrail 5건 패널** — GR1~GR5 각각의 현재값·임계·중단 권한 주체(2장 이해관계자)
- [ ] 임계 초과 시 알림 대상 표기 — 오조회(GR5)는 **컴플라이언스 즉시 통보**
- [ ] 페르소나 층별 분해 뷰 — SRS 4.2 대시보드 요구의 "페르소나 층별 분해"
- [ ] 발송 큐(`outbox`) 열람 화면 — 픽스처 모드에서는 실제 발송 대신 적재를 확인한다(FXT §5장)
- [ ] 계측 포인트 표기 — `outcome_response`

## 🧪 Acceptance Criteria (BDD/GWT)

**Scenario 1: 완주 화면에 독려가 없다**
- Given: 완주 확인 화면 시안 전체가 주어지고
- When: 재발송·리마인드·독려 문구와 버튼을 세면
- Then: 0건이다. 하나라도 있으면 GR4(실행 지원 오인) 위반이다(REQ-FUNC-010 · ADR-04).

**Scenario 2: 대시보드가 북극성과 완주율을 나란히 보여준다**
- Given: 대시보드 시안이 주어지고
- When: 북극성 지표의 배치를 확인하면
- Then: 실행 완주율(Blind-spot 층)이 같은 화면에 나란히 있다. 선택 후 실행 실패가 성공으로 읽히지 않게 하는 장치다(R4).

**Scenario 3 (실패 흐름): 분모 제외 비율이 빠지면 반려된다**
- Given: 북극성 패널 시안이 주어지고
- When: 분모 제외군 비율 표시를 확인하면
- Then: 존재한다. 없으면 게이팅을 지킬수록 지표가 나빠 보이는 착시가 생긴다(ADR-05 · TC-NF-009 ④).

**Scenario 4: Guardrail 5건의 중단 주체가 명시된다**
- Given: Guardrail 패널 시안이 주어지고
- When: GR5(오조회) 항목을 확인하면
- Then: 컴플라이언스가 PM을 우회해 단독 중단할 수 있음이 표기돼 있다(SRS §2장 · §11.2).

- 규제: **ADR-04** 측정 전용. 화면에 실행 개입 경로를 만들지 않는다
