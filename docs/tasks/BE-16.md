## 🧪 Acceptance Criteria (BDD/GWT)

**Scenario 1: 해지 결론에 경계 안내가 붙는다**
- Given: "해지" 항목이 포함된 조합 결론이 주어지고
- When: 응답을 생성하면
- Then: `scopeNotice` 가 채워져 반환된다. 미노출 0건(AC-03 · §6.1.3).

**Scenario 2 (실패 흐름): AI 문장의 금지어가 걸러진다**
- Given: 실행 대행으로 오인될 표현이 포함된 AI 문장이 주어지고
- When: 런타임 스캔을 통과시키면
- Then: 해당 문장이 사용자에게 노출되지 않고 적발이 기록된다(GR4).

**Scenario 3: 허용목록이 먼저 적용된다**
- Given: 요구사항이 의무화한 안내 문구가 주어지고
- When: 스캔을 실행하면
- Then: 허용목록으로 제거된 뒤 검사되어 오탐이 발생하지 않는다(GTD §2.2).

**Scenario 4 (실패 흐름): 모델 교체가 스캔을 건너뛰지 않는다**
- Given: 환경변수로 AI 모델 식별자만 바꾼 배포가 주어지고
- When: 배포 게이트를 실행하면
- Then: 금지어 스캔이 다시 수행된다. 코드 변경이 없다고 통과시키면 스캔 없이 배포되는 경로가 남는다(§1.5.1 신규 제약 ④).
