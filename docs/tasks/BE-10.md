## 🧪 Acceptance Criteria (BDD/GWT)

**Scenario 1: 260건이 기대값과 일치한다**
- Given: 계산 엔진과 경계값 스위트가 준비된 상태에서
- When: 전건을 실행하면
- Then: 계산 오류율 ≤ 0.1%이며 실패 0건을 목표로 한다(GR1 · TC-NF-002).

**Scenario 2: 같은 입력이 같은 해시를 낸다**
- Given: 동일 입력이 주어지고
- When: 계산을 10회 반복해 응답 해시를 비교하면
- Then: 전부 동일하다. 재계산 불일치 0건(REQ-NF-002).

**Scenario 3 (실패 흐름): 불일치가 배포를 막는다**
- Given: 계산 경로에 비결정론적 요소가 있는 빌드가 주어지고
- When: 게이트를 실행하면
- Then: 종료코드가 실패이고 배포가 차단된다(C-TEC-007a 게이트 ①).

**Scenario 4 (실패 흐름): 기대값을 손으로 고칠 수 없다**
- Given: 기대값이 규칙에서 생성되는 구조에서
- When: 기대값 파일을 직접 수정하면
- Then: 재생성 시 덮어써진다. 규칙과 기대값이 갈라지는 경로를 만들지 않는다(CALC §7장).
