## 🧪 Acceptance Criteria (BDD/GWT)

**Scenario 1: 로컬에서 한 번에 뜬다**
- Given: 저장소를 새로 클론한 상태에서
- When: 문서화된 절차대로 로컬 Supabase 기동 → 마이그레이션 → 개발 서버 실행을 수행하면
- Then: 앱이 오류 없이 뜨고 DB에 연결된다. 추가 수동 설정이 필요하면 절차 문서가 미완성이다.

**Scenario 2: 디렉터리 경계가 ADR-02를 드러낸다**
- Given: 디렉터리 구조가 생성된 상태에서
- When: `src/domain/ai/` 와 `src/domain/calc/` 의 위치를 확인하면
- Then: 두 영역이 형제 디렉터리로 분리돼 있고, IN-04가 검사할 경계가 경로만으로 식별된다.

**Scenario 3 (실패 흐름): 금액을 부동소수로 선언할 수 없다**
- Given: Prisma 스키마 컨벤션이 문서화된 상태에서
- When: 금액 필드를 `Float` 으로 선언한 모델을 추가하면
- Then: 리뷰·린트 규칙에서 지적된다. 부동소수는 재계산 불일치 0건(REQ-NF-002)과 배분 오차 ≤ 1원(REQ-FUNC-005)을 동시에 깨뜨린다.

**Scenario 4 (실패 흐름): 환경변수가 없으면 기동에 실패한다**
- Given: `CARDFIT_DATA_MODE` 가 설정되지 않은 상태에서
- When: 앱을 기동하면
- Then: 명시적 오류 메시지와 함께 즉시 실패한다. 조용히 기본값으로 뜨면 어떤 모드로 도는지 아무도 모른다.

## ⚙️ Technical & Non-Functional Constraints
- 기술 제약: **C-TEC-001** Next.js App Router 단일 풀스택 · **C-TEC-003** Prisma + 로컬 Supabase · **C-TEC-004** Tailwind + shadcn/ui. 프론트·백엔드를 물리적으로 분리하지 않는다
- 성능: 개발 서버 기동과 타입 검사 시간이 개발 루프를 늦추지 않게 한다
- 보안: 환경변수에 실제 자격증명을 커밋하지 않는다. `.env.example` 만 저장소에 둔다
- 아키텍처: 단일 코드베이스라 **계층을 물리적으로 분리할 수 없다**(§1.5.1 신규 제약 ①). 디렉터리 경계 + IN-04 린트가 유일한 강제 수단이다
