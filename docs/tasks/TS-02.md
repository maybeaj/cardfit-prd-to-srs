## 🧪 Acceptance Criteria (BDD/GWT)

**Scenario 1: 9건이 코드로 존재한다**
- Given: STD §2장의 TC 9건이 주어지고
- When: 테스트 스위트를 열거하면
- Then: `TC-NF-001` ~ `009` 에 대응하는 테스트가 전건 존재한다.

**Scenario 2: 결정론 테스트가 게이트로 쓰인다**
- Given: `TC-NF-002` 구현이 주어지고
- When: `IN-03` 배포 게이트 ①이 이를 호출하면
- Then: 종료코드로 통과·차단이 판정된다(C-TEC-007a).

**Scenario 3 (실패 흐름): 이중화가 한 겹이면 실패한다**
- Given: 애플리케이션 대조만 있고 RLS가 없는 환경이 주어지고
- When: `TC-NF-004` 를 실행하면
- Then: 독립 검증 단계에서 실패한다. 둘 다 켠 상태의 통과만으로는 이중화를 증명하지 못한다.

**Scenario 4 (실패 흐름): 분모 제외가 틀리면 실패한다**
- Given: 유지 결론 사용자가 분모에 포함된 산식이 주어지고
- When: `TC-NF-009` 를 실행하면
- Then: 실패한다. 분모 제외 오류 0건이 판정 기준이다(ADR-05).
