## 🧪 Acceptance Criteria (BDD/GWT)

**Scenario 1: 여정 1회에 이벤트 7종이 적재된다**
- Given: 픽스처 페르소나로 온보딩부터 조합안 선택까지 완주하고
- When: `events` 를 조회하면
- Then: 7종이 누락 없이 적재돼 있고 각 이벤트의 필수 속성이 채워져 있다(REQ-NF-009).

**Scenario 2: 레이턴시 원천이 쌓인다**
- Given: 계산·근거 엔드포인트를 여러 번 호출한 뒤
- When: `latency_samples` 로 p50·p95·p99를 산출하면
- Then: 값이 계산된다. 관측 수단이 없으면 REQ-NF-001은 검증 불가 상태가 된다.

**Scenario 3 (실패 흐름): 픽스처 모드에서 실제 발송이 없다**
- Given: `CARDFIT_DATA_MODE=fixture` 인 상태에서
- When: 완주 계측 배치를 실행하면
- Then: `outbox` 에 적재만 되고 외부 발송이 0건이다(FXT §5장).

**Scenario 4 (실패 흐름): 분모 제외가 틀리지 않는다**
- Given: "유지" 결론 사용자와 "변경" 결론 사용자가 섞인 코호트가 주어지고
- When: 북극성 산식을 계산하면
- Then: 유지 결론 사용자가 분모에서 제외되고 제외군 비율이 함께 산출된다(ADR-05 · TC-NF-009 ④).
